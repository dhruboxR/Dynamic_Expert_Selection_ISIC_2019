# Figure generation scripts

These scripts reproduce core figures from the repository outputs.

- `figure_01_dataset_distribution.py`
- `figure_02_model_comparison.py`
- `figure_03_v34_class_performance.py`

Run each script from the repository root or directly:

```bash
python paper_figures/figure_01_dataset_distribution.py
python paper_figures/figure_02_model_comparison.py
python paper_figures/figure_03_v34_class_performance.py
```
