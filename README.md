# Dynamic Expert Selection for Skin Lesion Classification

A research project exploring **dynamic expert selection using complementary CNN and Vision Transformer (ViT) models** for skin lesion classification on the ISIC 2019 dataset.

## 🔬 Project Overview

The repository contains research code, model implementations, experimental results, complementarity analyses, dataset audits, and supporting materials developed throughout the research process.

## 📂 Repository Contents

- **Models:** CNN and Vision Transformer implementations and trained model checkpoints.
- **Experimental Outputs:** Model performance, prediction analysis, and evaluation results.
- **Complementarity Analysis:** Pairwise model comparisons, prediction agreement, and hybrid candidate analysis.
- **Research Materials:** Scripts, visualizations, documentation, and paper-related assets.

## 🚧 Repository Status

**Continuous uploading and organization in progress.**

The repository is being published gradually, folder by folder. Additional source code, experimental outputs, analysis results, and research documentation will be added as the upload process continues.

**Please note:** The ISIC 2019 dataset itself is excluded from this repository.
